# X Game Assistant

A local-first Android game assistant prototype. No cloud API or account is required.

## Current prototype
- Dark Android interface
- Offline practice log saved on-device
- Adaptive rule-based suggestions based on practice history
- Android debug APK build through GitHub Actions

## Planned next
The actual game automation must be tailored to the target game and its rules. The app currently does not control other games and will not bypass anti-cheat or access controls.

## Build
The GitHub Actions workflow builds a debug APK and uploads it as an artifact.
